# 4622 Green Water Road, Regina

Listing website for **4622 Green Water Road, Regina, SK S4V 3H2** (Greens on Gardiner), listed at $599,900. Presented by The Real Estate Gurus. Agents: Sam Patel and Vipul Rabari, Royal LePage Next Level.

Built with **Gurus Listing**. It's a static single page (`index.html`, `photos/`, `images/`) with no build step.

## Put it online with Vercel (one time)

1. Go to vercel.com/new and import this repository.
2. Leave **Framework Preset** as **Other** and the build settings empty, then click **Deploy**.

Every commit to `main` redeploys the site.

## Updating the site

Edit the listing in Gurus Listing and click **Send to GitHub** (with this repository entered under Publishing). Claude pushes the changes here.
